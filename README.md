# RoboBooth
Robobooth is a fully automated, AI-powered system that captures cinematic branded videos using a 6-axis robotic arm, processes them instantly, and delivers them directly to users via WhatsApp.

Setup Guide

The Robotic Photobooth integrates a Doosan collaborative robot (cobot), Android camera, backend server, and WhatsApp chatbot to automate cinematic slow-motion video capture and delivery.

1. Prerequisites

The system requires:

Doosan Cobot (6-DOF)
Backend Server / Mini Desktop PC
Android Camera
USB A-to-C Cable
40"/50" Display
Arduino + Relay
Wired LAN for the cobot
Local Wi-Fi for the camera
2. Software Requirements

Install the following:

Python
FastAPI
Uvicorn
Flask
PySerial
Pillow
Jinja2
FFmpeg
Android Debug Bridge (ADB)
Arduino IDE
Ngrok
SQLite
3. Python Setup

Install Python and add the following directories to the system PATH:

C:\Users\<YourUsername>\AppData\Local\Programs\Python\Python3x\
C:\Users\<YourUsername>\AppData\Local\Programs\Python\Python3x\Scripts\

Verify the installation:

python --version

Install the required packages:

pip install fastapi uvicorn pyserial pillow jinja2

Verify the installed packages:

pip list
4. FFmpeg Setup

Add FFmpeg to the system PATH:

C:\ffmpeg\bin

Verify the installation:

ffmpeg -version

FFmpeg is used for video post-processing, including slow-motion effects, music, and branding.

5. ADB Setup

Add Android Platform Tools to the system PATH:

C:\platform-tools-latest-windows\platform-tools

Connect the Android camera to the PC and verify the device:

adb devices

The Android camera is controlled through ADB commands for recording, stopping recording, and transferring video files.

6. Arduino Setup

Install the Arduino IDE and required drivers.

Install the Python serial library:

pip install pyserial

Arduino + Relay is used as part of the hardware setup.

7. Ngrok Setup

Install Ngrok and create an account.

Start Ngrok on port 5000:

ngrok http 5000

Copy the HTTPS URL generated by Ngrok and configure it in wamain.py:

NGROK_URL = "https://abc123.ngrok.io"

Configure the WhatsApp Cloud API webhook as:

https://abc123.ngrok.io/webhook

Use the configured verification token:

verifytoken1234

Ngrok provides the public HTTPS URL required for WhatsApp webhook callbacks.

8. WhatsApp Cloud API Configuration

Configure the required credentials:

WHATSAPP_ACCESS_TOKEN = "YOUR_LONG_LIVED_ACCESS_TOKEN"
YOUR_PHONE_NUMBER_ID = "YOUR_PHONE_NUMBER_ID"
VERIFY_TOKEN = "verifytoken1234"

The WhatsApp Cloud API handles:

Receiving visitor messages
Sending chatbot responses
Delivering the processed video

9. Doosan Cobot Setup

Connect the cobot controller to the PC through Ethernet LAN.

The motion sequence is programmed in the DART UI and stored on the controller.

Configure the controller to:

Receive the start trigger through the digital output/input interface.
Wait for the required digital input signal.
Execute the programmed motion sequence autonomously.

10. Camera Setup

Connect the Android camera to the PC through ADB.

Check the connected device:

adb devices

The recording workflow is:

Connect PC to the Android camera through ADB.
Send an ADB command to start video recording.
Record while the Doosan executes its cinematic motion.
Send an ADB command to stop recording.
Pull the recorded video to the PC.

Example file transfer:

adb pull ... /selected_dir

The camera supports 1080p–4K recording depending on the phone model, with slow-motion capabilities of up to 240 FPS on high-end phones.

11. Application Files

The WhatsApp integration uses:

wamain.py — Flask server for WhatsApp integration.
main.py — Main photobooth control application for triggering video recording and processing.
database.py — Database initialization/management.

The system uses SQLite to track user sessions, phone numbers, video paths, and WhatsApp delivery status.

12. Run the Backend

Open the required command-line windows.

Command Window 1

Run the database:

python database.py

Start the WhatsApp Flask server:

python wamain.py

Start Ngrok:

ngrok.exe http 5000
Command Window 2

Start the main FastAPI application:

uvicorn main:app --reload

The backend server coordinates the chatbot, camera, cobot, video processing, and delivery workflow.

13. WhatsApp Webhook Endpoints
Endpoint	Method	Description
/webhook	GET / POST	WhatsApp webhook verification and message handling
/update_video	POST	Triggered after video creation to send the WhatsApp message
/videos/<filename>	GET	Publicly serves processed videos for WhatsApp download
/admin/*	Various	Admin dashboard for viewing sessions and videos

14. Test the Integration
Run wamain.py.
Start Ngrok on port 5000.
Verify the webhook through Meta's WhatsApp Cloud API dashboard.
Send Hello_Photobooth from the registered WhatsApp number.
Verify the message flow and frontend transition through the Flask console.
15. Security
Replace the default app.secret_key with a secure random value.
Store WhatsApp access tokens and API keys in environment variables.
Do not commit credentials to the repository.
Use HTTPS in production through a reverse proxy or hosted server rather than Ngrok.
